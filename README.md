# Statusy zadań

Prosta lista zadań z aktualnym statusem, datą następnej akcji, notatką i zdjęciami.

- Otwórz `index.html` w przeglądarce (bez instalacji, bez serwera).
- Kliknij zadanie, aby edytować status, datę, notatkę i dodać zdjęcia.
- Zaznacz checkbox, aby oznaczyć zadanie jako wykonane.

Dane są zapisywane lokalnie w przeglądarce (IndexedDB) – tylko na tym urządzeniu.
